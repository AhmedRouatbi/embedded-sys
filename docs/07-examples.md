# 07 — Examples

Location: `example/` in the repo. Full walkthrough: [`example/README.md`](../example/README.md). Each example is a complete project folder. Copy it anywhere and run `embsk setup`. Neither contains downloaded dependencies.

## 01-zephyr-template (base)

The Zephyr template the skill scaffolds (`skills/embedded-sys/templates/zephyr-app/`), instantiated for `nucleo_f767zi`.

| File | Origin |
|---|---|
| `app/src/main.cpp` | a Zephyr training project's blinky (itself from Zephyr `samples/basic/blinky`, Apache-2.0 header kept): blinks `led0`, logs the state every second; builds as C++ without `CONFIG_CPP` |
| `app/prj.conf` | course, unchanged (`CONFIG_GPIO=y`, `CONFIG_LOG=y`) |
| `app/CMakeLists.txt` | course + `HINTS $ENV{ZEPHYR_BASE}` |
| `app/west.yml` | course manifest (allowlist `cmsis_6`, `hal_stm32`, `path-prefix: deps`), Zephyr pinned to v4.4.2 |
| `.embsk/profile.json` | `board=nucleo_f767zi debugger=stlink log=uart hil=board` |
| `AGENTS.md`, `CLAUDE.md`, `.gitignore`, `.graphifyignore`, `docs/SPEC.md` (blank template) | generated by `embsk set` + `embsk scaffold` |

Intentionally omitted from the course repo: `app/modules/`, `tests/`.

Verified: a fresh copy goes through `embsk setup` → 3 projects fetched → build PASS, 28 KB flash, 35 s. The same `main.cpp` built for `nrf52840dk/nrf52840` after a board switch (allowlist `cmsis_6, hal_nordic`).

## 02-nucleo_f767zi-thermal-monitor (medium)

Built following the skill's phases. The process artifacts are included. **[`docs/WALKTHROUGH.md`](../example/02-nucleo_f767zi-thermal-monitor/docs/WALKTHROUGH.md)** replays the session with real outputs: the Alt+A configuration, the prompts, the spec interview, parallel lanes and spawn commands, TDD, the SIL + UART loop, two debugging sessions, the review, and graphify navigation.

| Part | Files |
|---|---|
| Spec (REQ-1…9, budgets, failure modes) | `docs/SPEC.md` |
| Plan (9 tasks, 3 lanes, spawn plan) | `docs/PLAN.md` |
| ADR (integer milli-°C, 8-sample average, hysteresis) | `docs/adr/0001-fixed-point-average-and-hysteresis.md` |
| Functional core (pure C) | `app/src/thermal.[ch]`: average, plausibility (−40…125 °C), hysteresis classifier, threshold validation, milli-°C formatting |
| Hardware shell | `app/src/monitor.[ch]`: sampler thread 10 Hz (`K_TIMEOUT_ABS_MS`), die-temp sensor, LEDs (`led0..2` aliases), button ISR → `k_work` (50 ms debounce), IWDG 1 s (`WDT_OPT_PAUSE_HALTED_BY_DBG`), 50 ms mutex timeouts |
| Shell | `app/src/shell_cmds.c`: `thermal status`, `thermal thresholds <warm_mC> <hot_mC>` |
| Boot | `app/src/main.c`: `boot ok v<APP_VERSION_STRING> reset=<hwinfo cause>` |
| Devicetree | `app/boards/nucleo_f767zi.overlay`: `die-temp0` alias, `&die_temp { status = "okay"; }` |
| Config | `app/prj.conf` (GPIO, SENSOR, ADC, WATCHDOG, HWINFO, LOG, SHELL, THREAD_NAME, ASSERT), `app/VERSION` 0.1.0 |
| Host tests | `app/tests/` ztest, 7 cases on `native_sim/native/64` |
| SIL target | the same app on `native_sim/native/64`: `app/boards/native_sim_native_64.{overlay,conf}`, simulated sensor + watchdog (`app/src/sim/sim_devices.c`, bindings `vnd,sim-temp`/`vnd,sim-wdt`), LEDs/B1 on `gpio_emul`, `sim` shell; scenario `app/sil/thermal.sil` (21 checks, REQ-3..7, 9) |
| Review | `docs/review/0001-sil-harness.md`: 2 findings proven by mutation, fixed |
| Code graph | `graphify-out/graph.html` (98 nodes, 10 communities), screenshot `docs/img/graphify-graph.png` |

Verified (no board attached):
- `embsk setup` from a fresh copy → build PASS, **0 warnings**, **91 KB flash / 16 KB RAM**, 41 s.
- `embsk verify` → build, host tests **7/7**, SIL scenario **21/21** over the UART (13.4 s), size: all PASS (30 s).
- Mutation check of the SIL: removing the debounce, lighting blue in HOT, or letting blue ignore FAULT each fails a scenario step. Board image unchanged by the SIL work (91 376 B).
- `embsk export` shows `die_temp` okay (from the overlay, line 13), `iwdg` okay, and `CONFIG_STM32_TEMP`, `CONFIG_IWDG_STM32`, `CONFIG_HWINFO_STM32`, `CONFIG_SHELL` = y.

Not verified: L4/L5 on hardware (real LEDs, contact bounce, watchdog reset, real temperature values). The walkthrough §8 lists the board steps.

## Reproduce

```bash
cp -r example/02-nucleo_f767zi-thermal-monitor /tmp/thermal && cd /tmp/thermal   # from the repo root
embsk setup && embsk verify      # ≈ 1 min incl. download; verify includes the SIL scenario
west flash -d build              # only with a board attached, after explicit OK
```
